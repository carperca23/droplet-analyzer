\chapter{Conclusión y Trabajos Futuros}

\section{Conclusión}

En este trabajo se ha mostrado la implementación desde cero de un sistema de detección de gotas con un enfoque clásico de visión por computador. Tras ver los resultados obtenidos en los experimentos desarrollados en el capítulo \ref{chap:resultados}, se puede concluir que la implementación es capaz de captar la dinámica general de un flujo de gotas, asumiendo cierto error en las detecciones individuales, sobre todo cuando hay oclusiones y gotas con diámetros inferiores a 10-15 píxeles. Sin embargo, hay que tener en cuenta este proyecto se ha desarrollado con la idea de implementar un sistema de detección de bajo coste y open source, para acercar esta tecnología a cualquier persona que quiera experimentar con ella y no tenga la posibilidad de invertir en hardware y software específico con licencias comerciales.

En este sentido, podemos decir que se ha cumplido el objetivo, y estamos ante una herramienta capaz de mostrar una instantánea general de la dinámica de un spray. Por otro lado, al estar construida con una arquitectura modular y código abierto, puede ser la base para futuras mejoras y adaptaciones a casos de uso específicos, ya que se pueden añadir fácilmente nuevos algoritmos de detección, eliminación de ruido, filtros, tracking, etc.

Por último, quiero destacar una reflexión personal: hoy en día el primer enfoque que se nos viene a la cabeza para resolver un problema suele ser el uso de alguna técnica de inteligencia artificial, y aunque estas técnicas son la solución óptima para muchos problemas, no debemos obviar los enfoques clásicos que, sin tener la misma potencia, pueden ser perfectamente válidos para ciertos casos de uso, siendo además mucho más sencillos de implementar, mantener y adaptar. A esto se añade la gran ventaja de la explicabilidad: con un pipeline clásico podemos entender el porqué de cada resultado, algo que con técnicas de deep learning no siempre es posible. Esta idea no es nueva; la primera regla de las \textit{Rules of Machine Learning} de Google \cite{zinkevich_rules_ml} dice: \textit{«No tengas miedo de lanzar un producto sin aprendizaje automático»}, recordándonos que la complejidad de un modelo no es sinónimo de idoneidad para el problema.

\section{Trabajos Futuros}

Conociendo las fortalezas y debilidades de la implementación actual, se proponen las siguientes mejoras a futuro, agrupadas en cuatro categorías:

\textbf{Mejoras en la segmentación:}
\begin{itemize}
    \item Intentar integrar algún modelo ligero de deep learning como YOLOv8-nano o MobileNet, entrenado con un dataset de gotas generado sintéticamente, para intentar mejorar la detección de gotas pequeñas y la oclusión.
    \item Probar a implementar la técnica de watershed para mejorar la detección de gotas solapadas.
    \item Mejorar la detección de gotas desenfocadas o que se encuentran en planos diferentes.
\end{itemize}
\textbf{Mejoras en el tracking:}
\begin{itemize}
    \item Sustituir o complementar Lucas-Kanade con un filtro de Kalman para mejorar la fragmentación en los casos que hay oclusiones, como se apreció en los resultados del experimento cinco mostrado en el capítulo \ref{chap:resultados}.
    \item Implementar el algoritmo húngaro de asignación, para optimizar el emparejamiento greedy actual entre detecciones y tracks.
\end{itemize}
\textbf{Mejoras en la interfaz gráfica y usabilidad:}
\begin{itemize}
    \item Permitir seleccionar una región de interés (ROI) para centrar el análisis en esa zona concreta.
    \item Añadir una herramienta de calibración automática, que permita medir el alambre calibrado y calcular la relación píxel-distancia real.
    \item Perfiles de parámetros guardables y cargables, para no tener que reconfigurar cada vez que se analiza un vídeo del mismo experimento
\end{itemize}
\textbf{Mejoras en la portabilidad y distribución:}
\begin{itemize}
    \item Facilitar un ejecutable para MacOS y Linux.
    \item Desarrollar una web ligera con Streamlit o Gradio, para permitir el análisis de vídeos sin necesidad de instalar nada en local.
\end{itemize}
